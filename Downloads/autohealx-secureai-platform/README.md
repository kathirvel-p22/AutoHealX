It combines multi-agent orchestration, predictive intelligence, and cryptographic auditability to deliver autonomous operations with human-in-the-loop governance.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm
- Firebase account (or use mock mode)
- Git

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/kathirvel-p22/AutoHealX.git
cd AutoHealX
```

2. **Install dependencies**
```bash
npm install
```

3. **Configure environment**
```bash
cp .env.example .env.local
```

Edit `.env.local`:
```env
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
GEMINI_API_KEY=your_gemini_api_key
APP_URL=http://localhost:3000
```

4. **Start development server**
```bash
npm run dev
```

5. **Access the platform**
```
http://localhost:3000
```

### Default Login
- **Email**: `admin@gmail.com`
- **Password**: Any password
- **Role**: Administrator (auto-approved)
