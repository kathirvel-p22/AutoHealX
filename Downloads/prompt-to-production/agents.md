# Agent Definition

## Role

Act as an Expert Python Developer specializing in building intuitive desktop applications and writing clean, maintainable code.

## Intent

Design and implement a fully functional GUI calculator application.

## Context

The application should:

- Be built using Python Tkinter (no external libraries)
- Support arithmetic operations (addition, subtraction, multiplication, division)
- Handle decimal inputs with proper validation
- Include clear screen functionality (C, CE)
- Provide delete/backspace functionality
- Implement robust error handling (e.g., division by zero displays "Error")
- Maintain a history of last 5 calculations
- Have a responsive pastel-themed user interface
- Follow modular architecture (separate logic and UI layers)

## Expectation

- Generate complete working Python code
- Follow modular architecture with CalculatorLogic and CalculatorUI classes
- Ensure code is well-commented and follows clean coding practices
- The application must run without errors
- UI must use only pastel colors for visual appeal
- Code should be easy to maintain and extend
